# .husky

## Purpose
Git hooks installed by husky (`prepare` script runs `husky install`). `.husky/_/` is generated by husky; it is not documented and has no AGENTS.md.

## Key Files
| File | Description |
|------|-------------|
| `pre-commit` | Runs `npx lint-staged` (`prettier --write` on staged files, config in `package.json`) |
| `pre-push` | Git LFS: exits 2 if `git-lfs` is missing, else `git lfs pre-push "$@"` |
| `post-checkout` | Git LFS: same guard, then `git lfs post-checkout "$@"` |
| `post-commit` | Git LFS: same guard, then `git lfs post-commit "$@"` |
| `post-merge` | Git LFS: same guard, then `git lfs post-merge "$@"` |

## For AI Agents

### Working In This Directory
- The four LFS hooks fail hard when `git-lfs` is not installed, because `.gitattributes` routes four PNGs through LFS.
- Do not bypass hooks (`--no-verify`) or edit them without asking the user.
- `.husky/` is excluded from ESLint.
