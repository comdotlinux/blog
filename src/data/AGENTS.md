## For AI Agents

### Frontmatter schema

Defined in `../content/_schemas.ts` (`.strict()`: no extra keys).

| Key           | Type     | Required | Notes                                                                        |
| ------------- | -------- | -------- | ---------------------------------------------------------------------------- |
| `title`       | string   | yes      |                                                                              |
| `description` | string   | yes      |                                                                              |
| `pubDatetime` | date     | yes      | ISO, e.g. `2022-11-26T23:03:05.000+00:00`                                    |
| `author`      | string   | no       | existing posts use `comdotlinux`                                             |
| `postSlug`    | string   | no       | URL slug override; otherwise `slugify(title)` (`../utils/slugify.ts`)        |
| `featured`    | boolean  | no       |                                                                              |
| `draft`       | boolean  | no       | drafts are filtered out of listings, tags and OG routes                      |
| `tags`        | string[] | no       | default `["others"]`; slugified for URLs                                     |
| `ogImage`     | string   | no       | if empty/absent, `/<title>.png` is generated by `src/pages/[ogTitle].png.ts` |

### Images

- Put files in `public/assets/YYYYMMDD/` (existing: 20221008, 20221010, 20221112, 20221126, 20221227).
- Reference as `/assets/YYYYMMDD/filename.png` in markdown.

### Working In This Directory

- Posts have a TOC (e2e checks it) and Shiki code blocks; keep headings structured.
- Never commit secrets or drafts you do not mean to publish; set `draft: true` to hide.

### Testing Requirements

`bun run build` validates frontmatter. Several e2e specs depend on `gradle-tricks`, `tmux-how-i-use-it` and the `gradle`, `automation`, `linux` tags; do not rename or retag them without checking `../../e2e/AGENTS.md`.
